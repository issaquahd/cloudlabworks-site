Twenty-five years from the server room to the region.

Alex Alvord designs cloud and AI infrastructure for people who have to run it afterwards. Enterprise architecture before the cloud, one of the first multi-cloud orchestration shops when it arrived, and since 2019 the field architect helping customers put Nutanix clusters inside Amazon Web Services, Azure and Google Cloud.

Advisory Solutions Architect, Hybrid Multicloud · Nutanix
Principal Architect · Cloud Lab Works · Duvall, Washington

Selected projects

  • Nutanix Cloud Clusters (NC2): hybrid multicloud in the fieldJoined the global NC2 unit in January 2021 when it had fewer than a dozen people; by 2026 it is a 250-plus organization. Design, proof-of-concept, and escalation work for customers running Nutanix clusters inside Amazon Web Services, Azure and Google Cloud: network and identity boundaries between on-premises and cloud, migration sequencing, availability and blast-radius design, and the operating cost after launch pricing ends.
  • The field-to-product loopRoughly a hundred tracked items carried from customer engagements back into the NC2 platform, its documentation, and engineering, including coordinating an expanded tiger-team response for Azure proofs of concept in 2023. Several became lasting improvements for the platform and the people who operate it. The habit: write down what broke, where, and what it cost, then make sure it reaches someone who can change it.
  • A cloud-native lab, built to be operatedThe Duvall lab is the test bench for everything published here: a Proxmox sandbox tier for untrusted workloads, an ARM cluster on a Turing Pi 2 for Kubernetes, an Apple-silicon host for private LLM inference, segmented networking with an OPNsense border and a Tailscale overlay, and rack power with a UPS. Zero trust is the stated design goal, and every component gets an owner, a health check, and a row in the inventory before it counts as deployed.
  • AI-assisted operations with written guardrailsAgentic tooling, local and hosted models, MCP servers, editor agents, run under a written constitution: which actions need a human, which need an undo engineered first, and which simply proceed and log. Memory lives in version-controlled files, not in a process. The point is not the chatbot; it is an operations layer that survives a restart and can be audited afterwards.
  • Multicloud cost, from the beginningThe FinOps interest dates to RightScale, whose model paired multi-cloud orchestration with one of the earliest cloud-cost guides. It shows up now as a standing rule in every design review: evaluate a vendor for what happens after dependency sets in, not for the launch price.
  • Medio Systems: cloud compute and analytics for telecom (2010)Cloud compute and analytics platform work for Medio Systems, the Seattle predictive-analytics company, January – June 2010: before "cloud" was a line item on most enterprise budgets. Medio's platform went public in March 2012 as the inGenius Suite: cloud-based predictive analytics on connected-device usage, tracking 105 million unique users and 550 million daily events at launch. TechCrunch, 15 March 2012.
