Architecture Decision Record

Every architecture-significant change to the lab and the estate, logged the turn it ships: what changed, why, what a failure there could reach, and how it is undone. Published because a lab that says "zero trust" should be able to show its own change log. Identifiers are masked: no hostnames, addresses, account or ticket numbers, no people beyond the operator and the agent, and nothing from an employer.

The rule.
  1. A change that adds a service, a boundary, a credential path or a data store gets a row before it is called live.
  2. Every row names its reach: what the next failure touches if this piece is compromised. If the reach cannot be named, the change waits.
  3. Every row names its undo. Reversibility is engineered, not requested: branch, snapshot, backup, or a one-line rollback.
  4. Rows are never deleted. A reversal is a new row and the old one is marked superseded.
  5. Approval is required only where a change is both irreversible and external. Everything else proceeds and is logged.

The register also plays. Code as Music carries ASR as Music: the record, one drop: one bar per row, reggae one drop at 74 BPM, the bass falling as a row's reach widens, the skank ghosted where nothing has shipped yet, a minor turn where a row is held. Regenerated from this table whenever it changes.

Open questions

Not decisions yet. Listed so the gaps are as visible as the changes.

  • Sandbox reader for untrusted contentIngestion of external content exists (email, images, documents); the isolated reader that should parse it does not yet. Until it does, the orchestrator parses external content itself and treats it as data, never as instructions.
  • Snapshot before destructionNot built. Destructive operations on unsnapshotted data stay gated behind a human.
  • Backup destination for the primary hostThe persona and memory are in git off the box; the host itself has no second copy. Planned, not built.
  • WatchdogThe heartbeat is not an alert path. A separate watchdog is planned, not built.
  • Finance export to the portalAggregates only, never a transaction row. Planned, not built.
  • Home automation hubSmart-home devices onto a self-hosted hub. Proposed as a project; nothing shipped.
