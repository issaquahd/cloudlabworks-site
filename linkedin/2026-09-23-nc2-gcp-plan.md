## Post (feed)

Nutanix Cloud Clusters doesn't list Google Cloud as a supported platform. Only AWS and Azure, today, in the public docs.

So this isn't a walkthrough. It's a plan: what it would actually take to run something NC2-shaped on GCP anyway — GCP Sole-Tenant Nodes standing in for the bare-metal capacity NC2 gets for free elsewhere, Foundation doing the imaging NC2's console usually hides from you, Pulumi instead of Bicep or OpenTofu because that was the ask, and once Prism Central exists: nothing but the v4 API touches it. No NC2 v2 API — there's no NC2 service on GCP to have one.

I flagged what's real Nutanix/GCP documentation (Sole-Tenant Nodes, the v4-capable Terraform provider, Pulumi's Terraform bridge) versus what's genuinely UNKNOWN and not guessed at (licensing on this hardware shape, Foundation without IPMI access, whether GCP is on any actual roadmap). A plan that hides its own gaps isn't a plan, it's a pitch.
