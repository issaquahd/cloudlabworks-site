 The substrate: GCE bare metal
 =============================

 Not a VM. Not nested virtualization. Not Bare Metal Solution.
 Ordinary GCE instances with -metal in the machine type,
 in your project, in your VPC.

 machine type                     vCPU   memory     local SSD
 ------------------------------   ----   --------   ---------
 z3-highmem-192-highlssd-metal     192   1,536 GB   72,000 GiB
 c4-standard-288-lssd-metal        288   1,080 GB   18,000 GiB
 c4-highmem-288-lssd-metal         288   2,232 GB   18,000 GiB

 Note: Google's GA blog swaps the memory on the two C4 rows.
 The Compute Engine docs above are the ones that are right.

 Nodes spread across Availability Domains in a zone, which maps
 to Nutanix rack awareness. Size n+1 for RF2, n+2 for RF3.
