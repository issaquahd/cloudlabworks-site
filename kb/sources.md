## The hierarchy

Every page in this knowledge base cites what it read, with the date it read it. When two sources disagree, the higher one wins.

1. **Product documentation on portal.nutanix.com.** The same guides are published as un-versioned PDFs under `download.nutanix.com/documentation/hosted/`, with the publication date on the cover and a change log inside. The PDFs are the copies this site reads, because they can be fetched, hashed and diffed; the portal pages render in a browser only.
2. **nutanix.dev and developers.nutanix.com.** API references, the API user guide, the SDKs, code samples.
3. **The Nutanix Bible** at nutanixbible.com, for architecture and how the pieces fit.
4. **Nutanix University on YouTube**, for walkthroughs and certification prep.
5. Launch blog posts, last. They describe a product on its launch day and are not maintained.

A claim that a product does or does not support a platform, region, version or feature is a live fact with an expiry date. The negative form deserves more scrutiny than the positive one.
